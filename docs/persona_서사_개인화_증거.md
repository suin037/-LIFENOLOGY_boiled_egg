# 성향 → 이직 서사 개인화 — 검증 증거

**요지:** 같은 예측 수치라도, 일기에서 뽑은 성향(persona_block)에 따라 이직 서사의
**강조 순서·리스크 프레임·톤**이 달라진다. **수치 자체는 절대 바뀌지 않는다**(정직성 원칙).

## 파이프라인

```
질문 일기(답변)  →  /analyze  →  disposition + persona_block(jobchange_material)
                                        │
예측 수치(월급·순수효과·재직기간)  →  /scenario  ← persona_block 주입
                                        │
                                  개인화된 이직 서사
```

`/scenario`는 persona_block이 있으면 프롬프트에 이렇게 지시한다:
> "위 '지표 강조 순서'가 높은 것부터 서술하고, '리스크 프레임'과 '전달 스타일'에 맞춰 톤을
> 잡아라. **수치는 절대 바꾸지 말고**, 불리한 축도 숨기지 마라(순서·톤만 조정)."

## 검증 조건 (셋 다 동일)

- 선택: 이직 · 나이 29 · 사회계열
- 예상 월급 **320만원** · 순수효과 **+7.9만원** · 예상 재직 **42개월**

## 결과 — 같은 숫자, 다른 서사

### 🛡️ 안정 우선형
> 강조 순서: 경제적안정도 → 삶의질 → 성장가능성 / 신중한 톤 / 지키려는 것: 지금의 안정

29살, 사회계열 전공으로 이직을 택한 평행우주의 당신을 잠시 들여다봅니다. 예상 월급은
320만원이고, 이 선택이 만들어내는 순수한 효과는 +7.9만원 — 크지 않지만 분명 플러스
방향이라는 점은 조용히 기억해둘 만합니다. 삶의 결 자체를 보면, 예상 재직기간이 42개월로
3년 반가량의 흐름이 예측되는데, 이 정도 기간이라면 일상의 리듬과 건강, 생활의 예측
가능성을 어느 정도 지키면서 자리를 잡아갈 여지가 있어 보입니다. 다만 42개월 이후의 변화는
아직 정해지지 않은 미지수이니, 지금의 안정을 지키는 선 안에서 이 숫자들을 한 번 더 찬찬히
들여다보는 시간을 가져보시길 바랍니다.

### 🚀 도전 우선형
> 강조 순서: 성장가능성 → 삶의질 → 경제적안정도 / 기회 프레임 / 지키려는 것: 자기실현·성장

29살, 사회계열 전공으로 이직을 선택한 이 평행우주의 당신은 무엇보다 성장 가능성에 마음이
움직였을 거예요. 새로운 환경에서 스스로 결정하고 성취를 쌓아갈 기회, 그 의미 자체가 이
선택의 핵심 동력이 됩니다. 다만 예상 재직기간이 42개월로 길게 이어지지 않을 수 있다는 점,
월급 320만원에 순수효과가 +7.9만원 정도로 크지 않다는 점은 현실적으로 감당해야 할
리스크예요 — 하지만 이건 안정보다 가능성에 무게를 둔 선택이 감수하는 자연스러운 대가이기도
하죠. 경제적 안정도는 다소 아쉬운 성적표지만, 자기실현과 성장을 지키려는 당신에게는 그보다
'어떤 경험을 쌓느냐'가 더 중요한 질문일지 모릅니다.

### ⚪ 대조군 (성향 없음)
29세, 사회계열 전공의 당신이 '이직'을 선택한 평행우주를 들여다봅니다. 이 선택은 월급
기준으로 약 +7.9만원의 순수효과를 가져오는데, 드라마틱한 변화는 아니지만 꾸준히 쌓이면
의미 있는 차이를 만들어냅니다. 예상 재직기간은 42개월(약 3년 반) 정도로, 단기적인
도전이라기보다는 중기적으로 자리를 잡고 안정을 찾아가는 흐름으로 보입니다. 월급 320만원이라는
현실적인 지표 안에서, 이 이직은 '극적인 반전'보다는 '한 걸음 더 나은 선택'에 가까운 모습입니다.

## 관찰

| | 안정 우선형 | 도전 우선형 |
|---|---|---|
| 첫 문장이 짚는 것 | 월급·플러스 효과(신중) | "성장 가능성에 마음이 움직임" |
| +7.9만·42개월 해석 | 안정 지키며 자리잡을 여지 | 가능성에 무게 둔 선택의 자연스러운 대가 |
| 맺음 | "지금의 안정을 지키는 선에서 찬찬히" | "어떤 경험을 쌓느냐가 더 중요" |
| **수치(320/+7.9/42)** | **동일** | **동일** |

→ 개인화는 **말투·강조·프레임**에서 일어나고, **예측 수치는 불변**이다.

## 재현 방법

키(`ANTHROPIC_API_KEY`)가 있는 `.env`가 있는 폴더에서 백엔드를 띄운 뒤,
`/scenario`에 동일 수치 + 서로 다른 `persona_block`을 넣어 호출하면 위와 같이 재현된다.

> 검증일 기준 실측. 서사 문구는 LLM 생성이라 호출마다 표현은 달라질 수 있으나,
> 강조 순서·톤의 방향성은 persona_block을 따른다.
